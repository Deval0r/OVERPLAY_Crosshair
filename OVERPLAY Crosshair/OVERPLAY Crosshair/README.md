# OVERPLAY Crosshair

A customizable crosshair overlay tool for Windows, built with Unity. Create and customize crosshairs with real-time preview and save/load functionality.

## Features

- **Customizable Crosshair Design**: Frame, hairs, and dot with various shapes and colors
- **Real-time Preview**: See changes instantly as you adjust settings
- **Preset System**: Save and load up to 5 different crosshair configurations
- **Hotkey Support**: Switch between presets using customizable keybinds
- **Export/Import**: Save crosshairs as images and share codes
- **Transparent Overlay**: Works as a desktop overlay that stays on top
- **HSV Color System**: Full color control with hue, saturation, and value sliders

## Controls

- **F2**: Toggle UI visibility (default)
- **Preset Keys**: Customizable keybinds for switching between presets
- **Mouse**: Drag the window to reposition
- **Escape**: Quit application

## Installation

1. Download the latest release
2. Extract and run the executable
3. The crosshair overlay will appear on your desktop
4. Use F2 to open the customization UI

## Customization

### Frame Settings
- Shape: Circle, Square, Triangle
- Color and opacity
- Scale and rotation
- Thickness

### Hair Settings
- Style: Even or custom angle distribution
- Count: Number of hair lines
- Color, opacity, and thickness
- Length and rotation

### Dot Settings
- Shape: Circle, Square, Triangle
- Color and opacity
- Scale and rotation
- Filled or outline

## Export/Import

- **Save Code**: Generates a unique code for your crosshair configuration
- **Load Code**: Import crosshair settings from a code
- **Generate Image**: Save your crosshair as a PNG image
- **Clipboard Support**: Copy/paste crosshair codes

## System Requirements

- Windows 10/11
- .NET Framework 4.7.2 or later
- DirectX 11 compatible graphics card
